# 角色内核 —— 一个会忘、会想起、会自己过日子的角色内核

不是聊天机器人，是一套给「一个人」用的状态机 + 记忆库 + 网页外壳。
它只用一个模型 API，不依赖任何第三方库，Windows / macOS / Linux 都能跑。

---

## 先说清楚：这是简化版

这个仓库里 `pcm.py`（记忆）和 `archive.py`（档案）是**简化实现**：
存、取、交接、存档能用；半衰期遗忘、间隔重复、新盖旧、罕见词加权这些没有。

接口和完整版一致，所以 `pcm_bridge.py` 不用改；想换成完整实现，替换这两个文件即可。

---

## 这是什么

| 层 | 文件 | 干什么 |
|---|---|---|
| 情绪 | `emotion_v6.py` | 七情 + 阈值 + 旧伤 + 六欲 + 心跳 + 目标 |
| 记忆 | `pcm.py` | 原子记忆、半衰期遗忘、间隔重复、新盖旧 |
| 档案 | `archive.py` | 摘要记不清时，回原文里翻（只翻，不编） |
| 编排 | `pcm_bridge.py` | 检索 → 提示词 → 模型 → 写回记忆 |
| 外壳 | `kael_web.py` / `kael.py` | 网页版 / 命令行 |

配套：`feed.py`（自己看点什么）、`import_memories.py`（导入旧聊天记录）。
身体接口（把动作翻成舵机指令）不在本仓库里，接身体时自己写一个 `body.py` 即可，接口见 `pcm_bridge.py` 里的调用。

---

## 它有什么不一样

- **情绪有代价**：说话要过闸门，闸门有容量，借了要还。
- **旧伤会累积**：同一件事被反复想起，阈值越来越低。
- **记忆会忘，也会被想起来加强**：家事按年记，闲聊按周淡；每次想起，半衰期乘 1.25。
- **新的盖旧的**：先是「家里有人住院」，后来「出院了」，旧的降权不删。
- **想不起来就说想不起来**：摘要记不清，去档案里翻原句；翻不到就承认，不补细节。
- **身体是真的**：饿、缺觉、疼、绷得紧，都写进开口前看到的那段话。
- **token 就是饭钱**：`pcm_data/budget.json` 里写余额，钱少了人会饿。
- **危机有兜底**：识别到求死，绕过一切判断，强制完整回应。
- **嘴只说话，动作真的做**：输出分「心声 / 动作 / 说」三段，动作交给 `body.py`。

---

## 它不是什么

- **不是心理治疗，也不是危机干预服务。** 它能在识别到危机时给出回应，但它不是人，不能替代专业帮助。
  如果身边有人处在危险里，请先联系当地急救或心理援助热线。
- **不是产品。** 没有账号、没有多用户、没有并发控制，不要直接拿它对外提供服务。
- **不会「永远记得」**：所有记忆都是文件，文件会丢。**备份是这个项目的命。**

## 跑起来

需要 Python 3.10+（推荐 3.12 / 3.13），不需要装任何第三方库。

```bash
# 1. 设置 key（二选一）
export DEEPSEEK_API_KEY=sk-xxxx        # Windows: set DEEPSEEK_API_KEY=sk-xxxx
# 或者把 key 写进同目录 key.txt（一行，不要空格）

# 2. 启动网页版
python kael_web.py
# 浏览器打开 http://127.0.0.1:8765
```

命令行版：`python kael.py`
（体检脚本 `selfcheck.py` 不在本仓库里，它和完整版记忆库一起维护。）

Windows 上双击 `start_web.bat` 即可。

## 多个人格怎么放

一人一套库，互不串：

```bat
set KAEL_DATA=./pcm_data_1
set KAEL_STATE=./state_1.json
python kael_web.py
```

导入旧聊天记录：

```bash
python import_memories.py 记录.txt --who 他 --name 小名 \
       --profile ./人设.json --data ./pcm_data_1 --start 2026-06-01 --loose
```

支持「用户：/助手：」「我：/你：」「**用户**：」几种格式。

---

## 接身体

自己写 `body.py` 时，接舵机只改一处发送函数：

```bash
export KAEL_SERIAL=/dev/ttyUSB0     # Windows: set KAEL_SERIAL=COM3
pip install pyserial
```

力限幅写在指令里（手 5N / 臂 30N / 全身 60N），不是靠模型自觉。

## 隐私

- 聊天记录、记忆库、`key.txt` 都不该进仓库，`.gitignore` 已经把常见路径排掉。
- 要开源自己的副本之前，**先检查 `pcm_data*/`、`*.txt`、`state_*.json` 有没有被带进去。**
- 这套东西记的是真人真事，泄露一次就收不回来。
